# 🌸 Ayman (آیمان)
**همراه متن‌باز، رایگان و بدون تبلیغات برای مادران؛ از بارداری تا دوران کودکی**

> *An open-source, privacy-first, multilingual companion app for mothers — supporting every step from pregnancy and breastfeeding to early childhood.*

---

### 🌐 اجرای آنلاین بدون نیاز به نصب (نسخه وب)
همین الان می‌توانید برنامه را مستقیم در مرورگر گوشی (اندروید و آیفون) یا کامپیوتر باز کنید:

👉 **[ورود به نسخه وب آیمان (https://emintm.github.io/Ayman/)](https://emintm.github.io/Ayman/)**

*(راهنما: پس از باز کردن لینک در مرورگر Chrome یا Safari، گزینه **Add to Home screen / افزودن به صفحه اصلی** را بزنید تا آیمان مثل یک اپلیکیشن واقعی روی گوشی شما نصب شود.)*

---

### 📱 دانلود نسخه اندروید (APK)
برای دریافت فایل نصبی اندروید:
1. وارد بخش **[Actions](https://github.com/EminTm/Ayman/actions)** شوید.
2. روی آخرین اجرای سبز (✅) کلیک کنید.
3. از پایین صفحه در بخش **Artifacts** فایل **`ayman-android-apk`** را دانلود و پس از خارج کردن از حالت ZIP نصب کنید.

## 🎯 هدف پروژه
پروژه **Ayman (آیمان)** با هدف بهبود کیفیت زندگی مادران، کاهش استرس دوران بارداری و پس از زایمان، و کمک به پیگیری سلامت و رشد نوزاد ساخته شده است. بسیاری از اپلیکیشن‌های مشابه دارای تبلیغات آزاردهنده، اشتراک‌های پولی گران یا مشکلات حریم خصوصی هستند. **آیمان** کاملاً رایگان، متن‌باز (Open-Source)، آفلاین‌محور و با اولویت حفظ حریم خصوصی (Privacy-First) توسعه داده شده است.

## ✨ امکانات پیاده‌سازی‌شده (نسخه 1.0.0)

### فاز ۱: پایه و دوران بارداری
- [x] پشتیبانی کامل از دو زبان **فارسی (RTL)** و **انگلیسی (LTR)** با فونت فارسی وزیرمتن (Vazirmatn)
- [x] محاسبه‌گر سن بارداری و تقویم هفته به هفته رشد جنین (با پشتیبانی از **تقویم شمسی و میلادی**)
- [x] **لگدشمار (Kick Counter):** ثبت و شمارش حرکات جنین با تایمر و تاریخچه
- [x] **زمان‌سنج انقباضات (Contraction Timer):** محاسبه مدت زمان و فاصله انقباض‌ها همراه با قانون ۵-۱-۱
- [x] **چک‌لیست بارداری و ساک بیمارستان:** دسته‌بندی‌شده با قابلیت افزودن موارد دلخواه

### فاز ۲: پس از زایمان، شیردهی و سلامت مادر
- [x] **تایمر و ثبت شیردهی:** تایمر مجزا برای سینه چپ/راست (با یادآور آخرین طرف) + ثبت شیشه و شیر دوشیده
- [x] **ثبت وضعیت نوزاد:** پیگیری خواب با تایمر ماندگار و ثبت تعویض پوشک
- [x] **سلامت روان و خودمراقبتی مادر:** شمارنده آب روزانه، چک‌لیست خودمراقبتی و چکاپ روزانه خلق‌وخو

### فاز ۳: رشد نوزاد تا کودکی
- [x] **پایش و نمودار رشد:** ثبت قد، وزن و دور سر همراه با مقایسه با محدوده نرمال سازمان بهداشت جهانی (WHO) برای پسران و دختران
- [x] **جدول واکسیناسیون:** پیگیری واکسن‌ها از بدو تولد تا ۶ سالگی
- [x] **راهنمای تغذیه تکمیلی:** راهنمای شروع غذای کمکی از ۶ ماهگی همراه با هشدارهای ایمنی
- [x] **نقاط عطف رشد (Milestones):** پیگیری مراحل رشد حرکتی و گفتاری کودک

### فاز ۴: زندگی بهتر و حریم خصوصی
- [x] **حالت همراه (Partner Mode):** نکات حمایتی ویژه همسر + کپی گزارش روزانه با یک کلیک
- [x] **پشتیبان‌گیری و بازیابی (Export/Import):** انتقال امن داده‌ها به صورت آفلاین

## 🛠️ تکنولوژی‌ها (Tech Stack)
* **فریم‌ورک:** [Flutter](https://flutter.dev/) (خروجی همزمان برای **Android** و **Web**)
* **ذخیره‌سازی داده‌ها:** معماری آفلاین‌محور (Local-First) روی دستگاه کاربر برای حفظ کامل حریم خصوصی
* **چندزبانه‌سازی (i18n):** پشتیبانی داخلی از فارسی و انگلیسی
* **طراحی رابط کاربری:** Material 3 با رنگ‌بندی آرامش‌بخش و خنثی
